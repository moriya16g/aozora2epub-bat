# aozora2epub-bat

青空文庫形式のテキストファイルを、Kindle で読める **EPUB3（縦書き）** にまとめて変換するツールです。
指定したディレクトリの下（サブディレクトリも含む）にある `.txt` と、青空文庫で配布されている `.zip` をすべて変換します。

- Python 3.8 以降の標準ライブラリだけで動きます（追加インストールは不要）
- Windows ではバッチファイル（`aozora2epub.bat`）にフォルダをドラッグ＆ドロップするだけで変換できます
- 出力した EPUB は EPUBCheck を 0 エラー・0 警告で通ります

## 準備

1. [Python](https://www.python.org/downloads/) をインストールします。
   Windows ではインストーラーの「Add python.exe to PATH」にチェックを入れてください。
2. このリポジトリをダウンロード（または `git clone`）します。

## 使い方

### Windows（バッチファイル）

| 操作 | 動作 |
| --- | --- |
| `aozora2epub.bat` をダブルクリック | `input` フォルダー内のファイルを変換し、`output` フォルダーに出力 |
| フォルダーを `aozora2epub.bat` にドラッグ＆ドロップ | そのフォルダー以下をすべて変換し、元のファイルと同じ場所に `.epub` を出力 |
| コマンドプロンプトで `aozora2epub.bat 入力フォルダー -o 出力フォルダー` | 下記のオプションも指定できます |

### コマンドライン（Windows / macOS / Linux 共通）

```sh
# 「books」以下を全部変換して「epub」に出力（フォルダー構成はそのまま再現）
python aozora2epub.py books -o epub

# ファイルを個別に指定。出力先を省略すると元のファイルと同じ場所に出力
python aozora2epub.py kokoro.txt 773_ruby_5968.zip
```

| オプション | 説明 |
| --- | --- |
| `-o DIR`, `--output DIR` | 出力先ディレクトリ。省略時は元ファイルと同じ場所 |
| `--horizontal` | 横書きで出力（既定は縦書き） |
| `--title-filename` | 出力ファイル名を「`[著者] 作品名.epub`」にする（既定は元のファイル名） |
| `-f`, `--force` | 変換済み（EPUB の方が新しい）ファイルも変換し直す |
| `--no-recursive` | サブディレクトリを検索しない |
| `--no-auto-tcy` | 縦書き時に、2 桁までの半角数字や「!?」を自動で縦中横にしない |
| `--encoding ENC` | 文字コードを指定（既定は自動判定：Shift_JIS / UTF-8） |
| `-q`, `--quiet` | 警告を表示しない |

2 回目以降の実行では、すでに変換済みのファイルはスキップされます。ファイルを追加してから再実行すれば、新しいものだけが変換されます。
1 ファイルの変換に失敗しても残りの変換は続け、最後に件数をまとめて表示します。

## Kindle で読むには

EPUB は Kindle 端末へ USB で直接コピーしても読めません。Amazon の **Send to Kindle** で送ってください（送信時に Kindle 形式に変換されます）。

- Send to Kindle（Web）: <https://www.amazon.co.jp/sendtokindle>
- Send to Kindle アプリ（Windows / Mac）にファイルをドラッグ＆ドロップ
- Kindle のメールアドレス（`〜@kindle.com`）宛てに添付ファイルとして送信

## 対応している青空文庫の注記

| 種類 | 例 |
| --- | --- |
| 表題・著者・訳者 | 冒頭の数行から作品名・副題・著者・訳者を読み取り、扉ページとメタデータにする |
| 記号の説明・底本情報 | 冒頭の「【テキスト中に現れる記号について】」は除去、末尾の「底本：」以降は巻末の「底本情報」ページへ |
| ルビ | `吾輩《わがはい》`、`｜見当《けんとう》`、`［＃「X」に「Y」の注記］` |
| 外字 | `※［＃「…」、第3水準1-85-54］`（JIS X 0213 の面区点）、`※［＃「…」、U+546D、…］`。変換できない外字は説明文を小さく表示 |
| くの字点 | `／＼`、`／″＼` → 〳〵、〴〵 |
| 改ページ | `［＃改ページ］` `［＃改丁］` `［＃改見開き］` `［＃改段］` |
| 見出し（目次に反映） | `［＃「X」は大見出し］`、`［＃中見出し］…［＃中見出し終わり］`、`［＃ここから小見出し］…`、同行・窓見出し |
| 字下げ | `［＃３字下げ］`、`［＃ここから２字下げ］…［＃ここで字下げ終わり］`、`折り返して○字下げ`、`改行天付き` |
| 地付き・字上げ | `［＃地付き］`、`［＃地から２字上げ］`、`［＃ここから地付き］…` |
| 傍点・傍線 | 傍点（ゴマ・白ゴマ・丸・白丸・三角・二重丸・蛇の目・ばつ）、傍線（二重・鎖線・破線・波線）。前方参照・範囲指定とも |
| 文字の装飾 | 太字、斜体、縦中横、小書き、上付き・下付き小文字、罫囲み、割り注、文字の大きさ（`２段階大きな文字` など） |
| 挿絵 | `［＃挿絵（fig1.png）入る］`、`［＃「説明」のキャプション付きの図（fig.png、横…）入る］` |
| 表紙 | テキストと同じ名前の画像（`作品.jpg` / `.png`）があれば表紙に使用 |

「ママ」「底本では〜」などの校訂注記や、対応していない注記は本文から取り除きます。
複数行にまたがる `［＃太字］…［＃太字終わり］` のような範囲指定にも対応しています。
